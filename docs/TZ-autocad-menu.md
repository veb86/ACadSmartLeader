# ТЗ на кнопки ACadSmartLeader в AutoCAD

В отдельной задаче добавьте элементы интерфейса, которые запускают существующие команды ACadSmartLeader. Исходная версия 0.1.4 запускает команды из командной строки. Сохраните эту возможность при любом состоянии меню.

## Состав

Добавьте вкладку **ACadSmartLeader** с панелью **Умные выноски**.

| Кнопка | Глобальная команда | Ожидаемое действие |
| --- | --- | --- |
| Создать | `_SL_CREATE` | Запросить точку стрелки и место полки. Сохранить доступ к ключу `_Rule`. |
| Создать групповую | `_SL_CREATE_GROUP` | Запустить создание отдельной выноски по подходящему правилу с суффиксом `_GROUP`. |
| Обновить | `_SL_UPDATE` | Открыть обычный запрос области обновления. При предварительном выделении сохранить выбор. |
| Правила | `_SL_RULES` | Открыть редактор правил текущего чертежа. |

В контекстном меню выделенной умной выноски добавьте пункт **Обновить умные выноски**, который также запускает `_SL_UPDATE`. Сохраняйте PickFirst и проверяйте принадлежность выносок плагину по XDATA `BobrovLeader`. На обычной MLeader без этого RegApp пункт отсутствует. Остальные команды перечислены в [README](../README.md#работа) и доступны из командной строки.

## Реализация

- Используйте частичный CUIX или поддерживаемый API меню AutoCAD. Соберите и подключите меню отдельно от логики выносок. При использовании CUIX зарегистрируйте его единственным способом. Основная настройка AutoCAD и меню других плагинов должны сохраняться.
- Используйте глобальные имена команд в макросах для русской и английской локализации AutoCAD. Передавайте команды активному документу. При занятой командной строке дождитесь её освобождения или откажитесь от запуска с сообщением. При обновлении сохраните предварительное выделение и штатные параметры `_All`, `_Select`, `_Force`.
- При старте без открытого DWG дождитесь готовности рабочего пространства. После смены рабочего пространства, переключения DWG, повторной загрузки или обновления пакета в каждом профиле должны быть одна вкладка, одна панель и один контекстный пункт. Снимайте программные регистрации при выгрузке. Учтите старую группу `ACADSMARTLEADER` из 0.1.3 и удаляйте только компоненты своего плагина.
- Поддержите поставляемые сборки AutoCAD 2020, 2021–2024 и 2025+. Если меню зависит от конкретной версии, выберите совместимую реализацию по диапазону `RuntimeRequirements`. При сбое загрузки меню оставьте команды доступными и выведите причину в командную строку.

## Приёмка

1. В CI проверьте полный состав сборки и соответствие каждой кнопки её команде. Проверьте совместимость ресурсов меню с маршрутами пакета и отсутствие дубликатов.
2. В AutoCAD на каждой поддерживаемой линейке проверьте чистый профиль и обновление профиля, где ранее загружалась группа `ACADSMARTLEADER`. Перезапустите AutoCAD и смените рабочее пространство. После выгрузки меню выполните все четыре команды из командной строки.
3. В двух разных DWG нажмите каждую кнопку и проверьте, что команда работает в активном документе. Создайте обычную и групповую выноски на одной цели. Измените данные цели и проверьте обновление по отдельным правилам.
4. Выберите одну из двух умных выносок, затем запустите обновление с ленты и из контекстного меню. Подтвердите область по умолчанию и проверьте, что обновилась выбранная выноска. Проверьте отсутствие пункта на обычной MLeader и поведение при активной команде.
5. Сохраните снимки ленты и контекстного меню из AutoCAD и логи проверок с номером версии AutoCAD и SHA сборки.
